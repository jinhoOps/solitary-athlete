## 오늘도 묵묵히, 잔디 한 칸.

산책도, 달리기도, 헬스도 좋습니다. 오늘 한 운동을 짧게 남겨 주세요. 묵묵이 하루의 인증을 잔디 한 칸으로 모아 줍니다. 쉬는 날을 탓하지 않고, 각자의 속도로 꾸준함을 쌓아 갑니다.

## 함께 운동 기록하기

1. **고독한 운동가 Discord에 참여해 주세요.**
2. **`#오운완`에 운동 메모나 사진을 남겨 주세요.** 묵묵이 저장을 마치면 ✅를 달아 줍니다.
3. **`#잔디`에서 함께 쌓은 기록을 확인하세요.** `/잔디`로 내 기록을, `/잔디 유저:@멤버`로 동료의 기록을 볼 수도 있습니다.

이미 멤버라면 [Discord 공지 채널](https://discord.com/channels/1559802401802952706/1559802402893340744)에서 이용 안내를 확인하세요. 이 채널 링크는 기존 멤버용입니다.

## 내 운동이 잔디가 돼요

- **텍스트 인증:** 초록 잔디 한 칸.
- **사진 포함 인증:** 한 단계 더 진한 초록 잔디 한 칸.
- **하루에 여러 번 인증해도 운동일은 1일.** 같은 날 사진을 하나라도 남기면 사진 잔디가 됩니다.

날짜는 한국 시간 기준입니다. 새 인증이 잔디에 반영되기까지 시간이 조금 걸릴 수 있습니다. `/잔디` 결과는 채널 구성원에게 보이며, 약 5분 뒤 지워집니다. 원본 인증과 저장된 운동 기록은 남습니다.

## 멤버 전용 웹보드도 있어요

올해와 지난 해의 잔디를 연도별로 돌아보고, 전체 멤버 또는 내 기록을 골라 볼 수 있습니다. 이번 달 운동 현황과 **운동왕 👑**, 날짜별 운동 메모도 함께 확인할 수 있어요.

**웹보드는 Discord 멤버에게만 공개합니다.** 참여 후 `#공지`에 올라오는 접속 링크를 이용해 주세요. 링크에는 매월 갱신되는 시크릿 코드가 포함되어 있습니다.

멤버에게 공유되는 정보는 표시명, 운동 날짜, 텍스트 메모입니다. 사진 원본과 첨부 링크는 웹보드에 옮기지 않습니다.

### 기술 구성

| 구성 | 사용 기술 |
| --- | --- |
| 인증 수집·현황판 | Python · uv · macOS launchd / GitHub Actions |
| 운동 기록 저장·접속 코드 검증 | Supabase Postgres |
| 슬래시 응답·결과 삭제·월간 코드 발급 | Supabase Edge Functions · TypeScript · Cron |
| 웹보드 | 바닐라 TypeScript · Vite · GitHub Pages |

로컬 수집은 맥북 실행 중 5분 간격이며, GitHub Actions 보완 수집은 매일 06:00 KST에 예약합니다. 실제 시작 시각은 지연될 수 있습니다. `/잔디`는 최근 28일과 최근 기록일 5개의 메모를 조회하고, 채널 현황판은 최근 14일을 일요일부터 토요일 순서로 표시합니다. 슬래시 결과 삭제는 예약 큐로 처리하므로 장애나 요청 지연 시 늦어질 수 있습니다.

웹보드는 멤버에게 제공하는 접속 코드로 기록을 조회합니다. 정적 웹 주소를 안다고 운동 기록을 바로 볼 수 있는 것은 아닙니다. 서비스 키·봇 토큰은 브라우저와 저장소에 포함하지 않습니다.
