# 묵묵 · Discord 이모지 6종

**기호 중심 ?·!·O·X·✓·👍은 [기호형 6종](symbols/README.md)과 [전용 ZIP](symbols/mukmuk-symbols-upload.zip)을 사용한다.** 기존 `mukmuk_yes`는 `mukmuk_exclaim`(놀람·감탄)으로 교체했다.

전신 스프라이트를 단순 축소하지 않고 얼굴과 큰 손동작 중심으로 새로 만든 이모지 전용 구성이다. 볼 홍조·무늬를 넣지 않고 묵묵의 크림색 얼굴·둥근 귀·짙은 윤곽선·새싹 아대를 유지한다.

[실제 크기 비교 PNG](preview.png) · [브라우저 미리보기](preview.html) · [업로드 파일 ZIP](mukmuk-emojis-upload.zip)

| 등록 이름 | 표현 | 자주 쓰는 상황 | 128px 업로드 파일 |
| --- | --- | --- | --- |
| `mukmuk_hi` | 인사 | 안녕·출석·반가움 | [PNG](128/mukmuk_hi.png) |
| `mukmuk_exclaim` | 놀람·감탄 | 놀람·감탄·오! | [PNG](128/mukmuk_exclaim.png) |
| `mukmuk_thanks` | 고마워 | 감사·하트 | [PNG](128/mukmuk_thanks.png) |
| `mukmuk_laugh` | 웃음 | 웃김·즐거움 | [PNG](128/mukmuk_laugh.png) |
| `mukmuk_tired` | 지침 | 힘들다·쉬는 중 | [PNG](128/mukmuk_tired.png) |
| `mukmuk_fighting` | 파이팅 | 운동 시작·응원·결심 | [PNG](128/mukmuk_fighting.png) |

- `128/`: 정사각형 RGBA PNG. Discord 등록용 파일 6개.
- `64/`: 작은 크기 재사용용 PNG.
- `source/`: 생성 원본. 업로드에는 128px 파일을 사용한다.
- `preview.html`·`preview.png`: 128·64·32px와 밝은/어두운 배경의 실제 크기 비교.
- ZIP을 풀면 등록용 PNG 6개가 나온다. 파일명과 등록 이름을 같게 사용한다.

Discord 권장 업로드 크기와 파일 제한은 [공식 도움말](https://support.discord.com/hc/en-us/articles/360041139231-How-to-Add-Emojis-on-Discord)과 [Emoji API 문서](https://github.com/discord/discord-api-docs/blob/main/developers/resources/emoji.mdx)를 확인했다. 업로드용 여섯 파일의 크기·알파 채널·256 KiB 미만 여부를 검사했다.

상태는 **파일 준비 완료**이며 서버 등록·실제 Discord 표시 확인과 구분한다. 실제 채팅 클라이언트와 운영체제에 따라 축소 표현은 조금 달라질 수 있다.
