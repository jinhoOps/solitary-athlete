| 이름 | 기호 | 용도 |
| --- | --- | --- |
| `mukmuk_gogo` | ㄱㄱ | 출발·진행 |
| `mukmuk_heart` | ♥ | 응원·애정 |
| `mukmuk_flex` | 💪 | 힘내·운동 |
| `mukmuk_eyes` | 👀 | 관심·지켜봄 |
| `mukmuk_dots` | … | 대기·머쓱함 |
| `mukmuk_fire` | 🔥 | 열정·불타는 중 |

기호를 크게, 묵묵은 모서리에서 작게 배치한다. 모래시계 대신 `…`로 대기와 머쓱함을 표현한다. `source/`는 생성 원본, `128/`는 서버 등록용, `64/`는 재사용용이다.

상태는 **서버 등록 완료**이다. 역할 제한 없이 서버 멤버가 사용할 수 있다. 등록 ID는 [manifest](manifest.json)에 기록한다.
