# 묵묵 · 기호 중심 이모지 6종

큰 기호를 먼저 읽고 작은 묵묵이 옆이나 모서리에서 반응하도록 구성했다. 기호 윤곽에 밝은 외곽선을 두어 어두운 배경에서도 형태를 구분한다.

[실제 크기 비교](preview.png) · [브라우저 미리보기](preview.html) · [128px 업로드 ZIP](mukmuk-symbols-upload.zip)

| 이름 | 중심 기호 | 상황 | 업로드 PNG |
| --- | --- | --- | --- |
| `mukmuk_question` | ? | 질문·모르겠음 | [PNG](128/mukmuk_question.png) |
| `mukmuk_exclaim` | ! | 놀람·감탄 | [PNG](128/mukmuk_exclaim.png) |
| `mukmuk_o` | O | 맞음·가능 | [PNG](128/mukmuk_o.png) |
| `mukmuk_x` | X | 아님·불가 | [PNG](128/mukmuk_x.png) |
| `mukmuk_check` | ✓ | 확인·완료 | [PNG](128/mukmuk_check.png) |
| `mukmuk_thumbsup` | 👍 | 좋아·동의 | [PNG](128/mukmuk_thumbsup.png) |

`128/`는 등록용, `64/`는 작은 크기 재사용용, `source/`는 생성 원본이다. 모든 등록 PNG는 정사각형·알파 채널과 256 KiB 미만 여부를 확인한다.

기존 얼굴 중심 `mukmuk_yes`는 제거하고 `mukmuk_exclaim`으로 교체했다. 기존 감정 묶음과 이 기호 묶음의 느낌표는 같은 파일이며 Discord에는 한 번만 등록하면 된다. 기호형 👍은 `mukmuk_thumbsup`으로 구분한다.

상태는 **파일 준비 완료**이며 서버 등록은 아직 하지 않았다.
