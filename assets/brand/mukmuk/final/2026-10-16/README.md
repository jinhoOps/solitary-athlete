# 묵묵 · 새싹 아대 최종본

2026-10-16 사용자 승인 캐릭터를 기준으로, 여섯 포즈의 초록 아대에 새싹 표식을 넣은 최종 시트다.

[최종 캐릭터 시트](mukmuk-character-sheet-v1.png)

| 위치 | 용도 | 표정·자세 |
| --- | --- | --- |
| 위 왼쪽 | 대표 이미지 | 손을 살짝 들어 인사하는 전신 |
| 위 가운데 | 정면 프로필 | 정면 상반신, 담담한 표정 |
| 위 오른쪽 | 스티커·와펜 시안 | 흰 외곽선이 있는 전신 |
| 아래 왼쪽 | 감정 · 만족 | 눈을 감고 작게 웃음 |
| 아래 가운데 | 감정 · 결심 | 두 손을 모아 조용히 의지를 표현 |
| 아래 오른쪽 | 감정 · 지침 | 운동 후 앉아서 쉬는 자세 |

## 유지할 특징

- 말랑한 모찌 같은 SD 체형, 작은 둥근 너구리 귀와 줄무늬 꼬리.
- 따뜻한 크림색 몸, 짙은 갈색 윤곽선, 단순한 눈과 입.
- 초록 운동 아대 위의 작은 아이보리 새싹. 새싹은 머리나 볼에 추가하지 않는다.
- 볼 홍조·점·무늬·수염은 넣지 않는다.
- 승인된 여섯 포즈의 몸매·표정·색감을 기준으로 후속 이미지를 만든다.
- 캐릭터 시각 기준은 루트 [DESIGN.md](../../../../../DESIGN.md)의 Mukmuk Mascot 절을 따른다.

파일은 여섯 구성을 한 장에 담은 1536×1024 RGBA PNG다. 시트 자체를 개별 포즈 파일이나 벡터 원본으로 표기하지 않는다. 개별 파일은 [스프라이트 폴더](../../sprites/README.md), 업로드용 정면은 [프로필 폴더](../../profile/README.md)에 있다. 기존 default·emotions·shiny 시안은 이 폴더의 최종 시트와 구분해 보존한다.
