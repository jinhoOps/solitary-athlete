# 묵묵 · 봇 프로필

완성 시트의 위 가운데 칸을 그대로 잘라 분리한 정면 프로필이다. 크림색 몸과 초록 새싹 아대를 유지한다.

**봇에 업로드할 파일: [mukmuk-profile-512.png](mukmuk-profile-512.png)**

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| [mukmuk-profile-source.png](mukmuk-profile-source.png) | 512×512 | 시트에서 잘라낸 프로필 원본 |
| [mukmuk-profile-1024.png](mukmuk-profile-1024.png) | 1024×1024 | 확대 출력본 |
| [mukmuk-profile-512.png](mukmuk-profile-512.png) | 512×512 | Discord 봇 프로필 업로드 |
| [mukmuk-profile-256.png](mukmuk-profile-256.png) | 256×256 | 작은 아이콘 |

모두 RGBA PNG이며 정사각형이다. 원형 표시에서 얼굴과 귀가 보이도록 여백을 둔다. 고독한 운동가 서버·채널의 새싹 아이콘과 구분해 묵묵 봇 프로필에 사용한다.

봇 전용 마크·배너는 `assets/brand/mukmuk/mark.png`·`mark.svg`·`banner.svg`·`banner.png`에 둔다. 공용 `assets/brand/mark.*`와 `banner.svg`는 기존 새싹을 유지한다. 6종 전체 시트는 [최종 시트](../final/2026-10-16/mukmuk-character-sheet-v1.png)에서 확인한다.
