# 묵묵 · 후속 구현 준비 현황

확인: 2026-10-14. 이번 마일스톤은 디자인 정의·문서 정리·로컬 검증이다. 수집기·함수·웹의 기능 코드는 시작하지 않았다.

토큰·연결 문자열의 실제 값은 이 문서에 복사하지 않는다. DB 회귀 검사 통과는 수집기·슬래시·실제 메시지 삭제·웹 동작 검증을 뜻하지 않는다.

## 실연동 전에 필요한 설정

| 항목 | 현재 확인 | 필요한 시점 |
| --- | --- | --- |
| `DISCORD_BOT_TOKEN` | 로컬 값 없음. 생성·재설정하지 않음 | Discord 수집·리액션·현황판 실제 확인, 명령어 등록 |
| `MUKMUK_REPLY_TOKEN_KEY` | 로컬 값 없음 | 슬래시 큐 암호화·삭제 워커 통합 |
| `MUKMUK_CLEANUP_SECRET` | 로컬 값 없음 | 내부 삭제 함수·Vault/Cron 호출 |
| Deno 테스트 도구 | CLI 없음 | Edge 함수 구현·형 검사·테스트 |
| Edge 함수·Cron·GitHub Secrets | 아직 배포/등록 전 | 관련 코드 검증 후 배포 마일스톤 |
| `DASHBOARD_URL` | 웹보드 미배포로 비어 있음 | Pages 배포 후 안내·현황판 링크 |

코드 작성과 가상 데이터 검증을 시작할 기반은 준비됐다. 실제 Discord 연동은 봇 토큰 준비가 필요하고, 공개 서비스 완료는 각 배포·실서비스 검증을 통과한 뒤 판단한다. 공용 DB의 전역 설정·기존 앱·프로젝트 키를 바꾸지 않는다.
