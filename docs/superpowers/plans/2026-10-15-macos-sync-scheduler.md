# 맥북 수집 스케줄러 전환

사용자 결정: 켜진 개발 맥북에서 5분마다 수집, GitHub는 매일 06:00 KST 보완 수집.

1. 앱 수집 전체에 전용 DB 트랜잭션 advisory lock을 적용한다. 별도 연결에서 잠금을 유지해 메시지별 저장 트랜잭션을 보존하고, 다른 수집기가 소유하면 성공 상태로 건너뛴다. 실제 PostgreSQL에서 동시 배제·실패 후 해제를 검증한다.
2. macOS LaunchAgent 설치 스크립트와 제한 시간/회전 로그 실행기를 추가한다. 검증한 Python 소스를 사용자 Application Support에 복사하고 기존 .env 경로만 전달한다. 00·05·…·55분 달력 예약, 등록 직후 실행. 로그아웃/전원 종료 동안에는 실행하지 않으며 절전 중 놓친 달력 일정은 깨어난 후 합쳐 실행한다.
3. GitHub cron은 0 21 * * * UTC로 변경한다. 서버의 슬래시·5분 삭제·주간 코드 예약은 유지한다. 웹/문서의 수집 주기 안내를 갱신한다.
4. 테스트와 리뷰 → 로컬 설치 → launchctl 상태 및 DB 갱신 확인 → 커밋·푸시·머지 → 다음 로컬 예약 실행 확인. 이후 수집기 변경 시 설치 스크립트를 다시 실행해 로컬 런타임을 갱신한다.
