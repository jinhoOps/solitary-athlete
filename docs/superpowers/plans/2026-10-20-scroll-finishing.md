# 잔디·멤버 스크롤 마감 구현 계획

목표: 월 라벨 절단을 부드럽게 처리하고 글자 크기 변경 후에도 선택 멤버를 노출한다.
사용자가 추천안 선택과 즉시 구현을 요청한 범위 내에서 현재 작업자가 순서대로 실행한다.

- [x] 월 라벨: 기존 셀 행 페이드의 위치와 높이를 유지한다. 월 라벨에는 고정 요일 오른쪽부터 12px의 별도 소프트 마스크를 적용한다. 시작·끝에서는 해당 방향 페이드를 제거한다.
- [x] 멤버: 목록과 각 칩 크기를 관찰하고 프레임당 한 번 재배치한다. 배치 완료 후 측정값을 저장해 숨김 처리로 생기는 반복 관찰을 막는다. 선택 칩의 15px 여유를 유지한다.
- [x] 모바일: 전체·찾기 버튼과 최소 96px 목록이 한 행에 들어가지 않을 때 두 버튼을 1행 양끝, 개인 목록을 2행 전체 폭에 배치한다.
- [x] 브라우저 회귀 검사로 월 마스크 경계, 고정 컨테이너 내 글자 확대 후 선택 노출, 두 행 위치를 먼저 재현한다.
- [x] DESIGN.md를 갱신하고 단위 검사·타입 검사·빌드·브라우저 전체 검사를 수행한 뒤 커밋·푸시한다. 이번 요청에는 main 병합·배포를 포함하지 않는다.

검증: 단위 57개, 브라우저 94개 전체 검사, 타입 검사·정적 빌드와 360px 100%·320px 200%·768px 100% 화면 확인. 기존 기하 검사에서 글자 확대 직후 필터 재배치를 기다리도록 프레임 동기화를 추가했다.
